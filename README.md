# youtube-foucus-mode
A Chrome extension that helps you stay focused on YouTube using custom channel/title filters, optional Groq AI classification, and a configurable interface cleaner to hide distracting elements like Shorts, recommendations, comments, and more.



Study Focus for YouTube is a Chrome extension designed to turn YouTube into a more focused study environment.
It lets you create custom allow/block filters for video titles and channels, optionally uses Groq AI to classify unknown videos, and includes a YouTube interface cleaner to hide distracting elements such as Shorts, topic chips, recommendations, comments, live chat, and more.

Manual filters are checked first, so AI is only used when necessary, reducing API usage while keeping the extension fast and customizable.
